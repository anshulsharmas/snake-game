# Snake Game

A classic Snake game implementation in Python using Pygame.


## Features
- Classic snake gameplay
- Score tracking
- Adjustable game speed
- Responsive controls
- Modern visual design

## Requirements
- Python 3.x
- Pygame

## Installation
1. Clone the repository
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## How to Play
1. Run the game:
   ```bash
   python -m snake_game.main
   ```
2. Use arrow keys to control the snake
3. Press +/- to adjust game speed
4. Press F to toggle fullscreen
5. Press SPACE to restart after game over

## Controls
- ↑ Up Arrow: Move up
- ↓ Down Arrow: Move down
- ← Left Arrow: Move left
- → Right Arrow: Move right
- +: Increase speed
- -: Decrease speed
- F: Toggle fullscreen
- SPACE: Restart game
